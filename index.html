My Obsidian Sync

My Obsidian Sync is a personal OAuth application used to connect the GSync plugin for Obsidian to Google Drive.

Purpose

The application is used for personal file synchronization between Windows and Android.

Google Drive Access

The GSync plugin uses Google Drive API access to synchronize Obsidian vault files. Files are transferred directly between the user's device and Google Drive.

This is a personal application and is not affiliated with Google or Obsidian.
