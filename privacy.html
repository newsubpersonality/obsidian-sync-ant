Privacy Policy

Last updated: October 21, 2026

1. About this application

My Obsidian Sync is a personal OAuth application used to authorize the GSync plugin for Obsidian to access Google Drive.

2. Purpose of data access

Google Drive access is used to synchronize Obsidian vault files between the user's Windows and Android devices.

3. Data processing

The application is intended for personal use. Google Drive files are accessed by the GSync plugin for synchronization purposes.

4. Data storage and sharing

The OAuth application does not operate a separate server for storing synchronized files. Files are stored on the user's devices and in the user's Google Drive account.

5. Access control

The user controls access to Google Drive through their Google Account permissions. Access can be revoked at any time through Google Account security settings.
